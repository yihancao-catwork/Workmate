# Workmate Python Outline

## 1. 目标

基于 DockCat 的产品形态，设计并实现一个适配 Windows x64 的本地桌宠应用，开发语言统一使用 Python。

当前阶段的目标不是一次性做完整正式版，而是先做一个最小可运行 demo，用来验证以下体验：

- 一只常驻桌面边缘的陪伴型宠物。
- 具备 resting、walking、dragged 三种最基本状态。
- 支持透明悬浮窗显示。
- 支持 walk 动画。
- 支持鼠标拖拽。
- 支持右键菜单退出。
- 支持少量本地设置持久化。

平台目标：

- Windows 10/11 x64
- 全本地运行
- 不依赖联网服务

## 2. 技术路线

本项目统一采用：

- Python 3.14
- PySide6

选择 PySide6 的原因：

- 足够支持透明窗口、无边框窗口、置顶窗口、托盘菜单、图片渲染和定时器。
- 比 tkinter 更适合做桌面宠物这类需要透明背景和 PNG 动画的应用。
- 开发速度快，适合先做可运行原型。
- 未来如果需要扩展设置窗口、对话气泡和资源包加载，也能继续沿用。

当前不考虑切换到其他语言，也不再保留 WPF 作为主方案。

## 3. 对标 DockCat 时保留的核心抽象

虽然实现语言改为 Python，但仍保留 DockCat 中真正有价值的抽象层，而不是照搬平台实现。

保留的核心思路：

- 状态机驱动宠物行为。
- 静态姿势图和 walking 动画帧分离。
- 资源文件按状态分类组织。
- 配置持久化到本地 JSON。
- 后续可以继续扩展提醒、出门、收藏品和资源包。

当前阶段不实现的部分：

- 提醒系统
- 出门系统
- 收藏品箱
- 多显示器适配
- 复杂任务栏定位
- 完整资源包 fallback
- 精细 alpha hit test

## 4. 最小 Demo 范围

第一版最小 demo 只做这些能力：

1. 启动后显示一个无边框透明桌宠窗口。
2. 默认显示 resting 图。
3. 定时切换 walking 动画帧。
4. 宠物沿水平方向缓慢移动。
5. 鼠标左键可拖拽宠物。
6. 鼠标右键或托盘菜单可以退出程序。
7. 保存宠物最后位置和缩放设置。

最小验收标准：

- 程序能启动。
- 桌面能看到宠物。
- 动画能播放。
- 拖拽有效。
- 重启后位置可恢复。
